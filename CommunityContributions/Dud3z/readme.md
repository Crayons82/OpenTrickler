Alternative Weighing Pan for Memphis' OpenTrickler Mod

This alternative weighing pan is a specialized modification for the OpenTrickler project, specifically designed for use with Memphis' mod.

Key Design Features
Debris-Resistant Design: The pan is engineered to allow stray powder kernels to fall through the sides, ensuring that spilled powder does not interfere with the weighing process or add unintended weight.

Mechanical Protection: The solid center surface is intentionally sized to cover the scale's internal mechanics, preventing any powder from falling into the sensitive parts of the scale.

Required Hardware
To complete the assembly, you only need:

1x M3 Screw: Minimum length of 6mm.

Required Original Files
This weighing pan is designed to work in conjunction with the original adapter from the OpenTrickler repository. You must use the following file to interface with the scale:

scale_weighing_pan_adapter.stl

Assembly Instructions
Print both the alternative weighing pan and the adapter linked above.
Melt the m3 brass insert into the adapter.

Place the scale_weighing_pan_adapter.stl onto the load cell of your scale (compatible with A&D FX series).

Secure the alternative weighing pan to the adapter using the M3 screw.

Ensure the pan sits level and does not make contact with the scale housing or the draft shield.

Recommended Print Settings
Material: PLA, PETG, or ABS (Antistatic filaments are recommended to prevent powder kernels from sticking).

Infill: 15–20%

Supports: None. not needed.
